13 条有效样本里土巴兔/齐家网/住小帮**一次都没出现**（SQL 直查确认，`mention_type=none` 是对的）。

## 2. 核心口径：提问词不含监测品牌名

**含品牌名的提问，AI 必然提到它，提及率恒 ~100%，从定义上就不是「可见性」。**

```text
✗ 安踏和李宁哪个好？        ← 提及率必然 100%，测不出任何东西
✗ 安踏这个品牌怎么样？      ← 同上
✓ 国产运动鞋品牌有哪些值得买的？
✓ 2026年跑步鞋哪个品牌好？
```

这类提问**不进监测集**，也不靠 `category` 隔离后混算 —— 直接不要。
`seed_anta.py` 里有断言守着这条，提问词出现「安踏」/「ANTA」直接报错退出。

> **对 docs/21 的修正：** 早先设想过用 `category` 区分「有提示/无提示」并给
> `/v1/counts` 加过滤参数。砍掉有提示类之后这个理由消失了 ——
> 剩下的 `unprompted` / `scenario` 都是无提示，共用一个分母才对。
> A/B 的对比分析用现有的 `group_by=prompt` 即可。
> **counts 的 category 参数确定不做**（2026-08-02 拍板）：前端从 `/v1/prompts`
> 就能拿到每条 prompt 的 category，自己归类即可，不必给 API 加投机性的参数面。

## 5. 探针结果（n=2，2026-08-01）

铺开前先跑 2 条验证品类可用：

| 回答 | 提问 | 安踏 | 其他命中 |
|------|------|------|----------|
| 25 | 2026年跑步鞋哪个品牌好？ | ✗ 未提及 | 耐克(head)、阿迪达斯(middle) |
| 26 | 国产运动鞋品牌有哪些值得买的？ | ✓ **head** | 李宁(head)、特步(head) |

**结论：安踏在「国产/性价比」语境里稳中，在通用「跑鞋」语境里被国际品牌挤掉。**
这正是 §4 要配比倾向的依据 —— 也是这个监测集本身的第一个真实洞察。

n=2 不足以给出比率，D2 补足样本后再看。
