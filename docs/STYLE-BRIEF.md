# GEO 监测产品 · 前端风格情报

> 用途：给「高度风格化」的 GEO（Generative Engine Optimization）监测产品定视觉立场。  
> 对象：登录页、监测台、落地页。  
> 原则：**先换设计立场，再换组件。** 换皮肤解决不了开源后台脸。

---

## 0. 先分清两件事

**g1geo.com 是产品对标，不是视觉对标。**

| 层 | 对标谁 | 作用 |
|---|---|---|
| 产品 / 功能 | g1geo、Peec、Profound、Goodie、Scrunch | 监测什么、指标怎么切、Prompt / 引用 / 竞品 |
| 视觉 / 气质 | Linear、Vercel、Raycast、Palantir、Bloomberg | 贵、不像开源后台、像「监测」而不是 CMS |

g1geo 方向对（国内 GEO：DeepSeek / 豆包 / 元宝 / 千问 / 文心 / Kimi），页面本身是浅底、功能块、蓝按钮、微信二维码——典型国内 SaaS 落地页。抄它，风格问题会更严重。

---

## 1. 「开源风格」的配方（必须整套拆掉）

几乎所有「简约但古板」的前后台，都是同一套默认脸：

- 组件：shadcn/ui 默认皮肤（或 Ant Design / Element / Naive 默认主题）
- 字体：Inter / 系统黑体 / 阿里巴巴普惠体
- 颜色：zinc / slate 灰底 + indigo-600 / 品牌蓝 主按钮
- 布局：圆角卡片（`rounded-xl`）栅格，每块一个白底描边
- 图标：Lucide / Heroicons，24px，线性
- 登录：**灰底 + 居中白卡片 + Logo +「欢迎回来」+ 邮箱密码 + 主色按钮**
- 文案：「一站式智能监测平台」「登录以继续」「欢迎回来」

换主色、加暗色模式、换一套插画，都还是这张脸。要动的是 **token、骨架、签名物件、文案**，不是卡片圆角从 12 改到 8。

## 2. 三条风格路线（只选一条当主轴，不要混）

### A. 克制黑（最不容易翻车）

近黑画布、一种强调色、极细边框、信息密但不乱。登录页几乎没有装饰，靠字体、留白、对比显贵。

- 气质：Linear / Vercel / Raycast / Resend
- 适合：要「看起来像 2026 年顶级 devtools」、面向品牌 / 增长团队
- 风险：跟风的人太多，做不好会变成「又一个暗色 shadcn」
- 过关标准：关掉强调色后，版面仍然成立

### B. 情报指挥台（最像「监测」）

密度即豪华。多栏、等宽数字、实时回答流、品牌名在回答里被点亮。登录像走进控制室，不是填表。

- 气质：Profound 产品台、Palantir Gotham、Bloomberg Terminal
- 适合：GEO 监测的核心场景（可见度、提及、引用、竞品）
- 风险：发光、扫描线、霓虹一多，就变成科幻片道具
- 过关标准：看起来像值班的人在用，不像概念图

### C. 编辑部 / 杂志风（最不像 SaaS）

衬线大标题 + 无衬线正文 + 单色点缀。登录像封面，监测台像排版后的报告。

- 气质：Stripe Press、高端作品集、部分 Framer 站
- 适合：落地页、报告、登录；数据页要克制
- 风险：表格和图表容易「装不上」
- 过关标准：打印成 PDF 仍然像品牌报告，不像后台截图

### 本项目建议

**A 做底，B 做核心物件。**

- 壳：近黑、一种强调色、紧追踪无衬线 + 数据等宽（A）
- 灵魂：AI 回答流里品牌高亮、引用关系、实时层（B）
- C 只用于封面句、空状态、导出报告封面，不要铺满表格页

一句话立场（可直接当设计 brief）：

> 暗色情报终端。一种磷光强调色。回答流是唯一装饰。登录和监测台共用同一个签名物件。

## 3. 产品层参考（同赛道，抄信息架构）

国际 GEO / AEO 比国内站成熟一整代。抄 **指标怎么切、页面怎么分、表格怎么读**，不要抄他们的 CSS。

### 3.1 Peec AI — 最好看的「干净监测台」

- 地址：https://peec.ai
- 定位：营销团队的 AI Search Analytics
- 气质：浅色、极克制、信息清晰
- 核心指标三件套：
  - **Visibility** 可见度（多少对话提到你）
  - **Position** 位次（在回答里排第几）
  - **Sentiment** 情感（AI 怎么描述你）
- 页面切法：Overview / Prompts / Sources / Models / Settings
- 可偷：
  - 三指标 + 趋势图 + 竞品表 的首页结构
  - Prompt 用标签组织，而不是一长串关键字
  - 引用来源按 UGC / Editorial / Corporate 分类
  - 筛选条：品牌、时间、标签、模型，始终在顶上
- 不要偷：浅灰企业后台脸、emoji 当图标、过分「友好」的空状态
- 一句话：学它怎么让人 10 秒看懂；别学它怎么「好看」

### 3.2 Profound — 暗色企业指挥台

- 地址：https://www.tryprofound.com
- 定位：企业级 Answer Engine Optimization
- 气质：近黑、侧栏、单色面积图、排行榜
- 可偷：
  - 暗色壳 + 单色图表（不要彩虹折线）
  - Home = 可见度分数 + 行业排名 + 时间粒度
  - 侧栏按工作对象切：Industry / Topic / Model / Citation / Improve
  - 「Last 24h / 7d / 30d」作为一等公民
- 不要偷：过重的营销站动效、什么都做成 Agent
- 一句话：这是「监测产品该有的气场」

### 3.3 其他同赛道（当竞品清单，不当视觉圣经）

| 产品 | 地址 | 看什么 |
|---|---|---|
| Goodie | https://www.goodie.ai | 工作流和内容动作，不只是看数 |
| Scrunch | https://scrunch.com | 监测 + 审计 + 优化一条链 |
| AthenaHQ | https://www.athenahq.ai | 企业可见度项目怎么铺 |
| Otterly | https://otterly.ai | 轻量监测、报告感 |
| Rankscale | https://rankscale.ai | 引用源、入门价位产品怎么讲 |
| Conductor / Semrush / Ahrefs Brand Radar | 各自官网 | SEO 巨头怎么把 AI 可见度塞进老后台（多为「加模块」，气质一般） |

国内除 g1geo 外，多数仍是咨询公司站 + 表单获客，视觉价值低。功能可以对（平台多选、免费检测、案例报告），皮肤不能对。

## 4. 气质层参考（跨赛道，抄「贵」）

这些不是 GEO。它们是 2025–26 年「不像开源后台」的标准答案。

### 4.1 克制黑四件套

**Linear** — https://linear.app  
近单色、一种强调色、非必要直接删。键盘优先。半个行业的暗色克制都从这来。  
偷：低对比描边、紧字距标题、静音的表面层级、Command palette。  
不偷：项目管理的信息架构。

**Vercel Dashboard** — https://vercel.com  
纯黑白、可收起侧栏、登录页几乎只有身份按钮。  
偷：满屏虚无的登录、表格/列表即界面、零插画。  
不偷：部署产品的顶栏结构原样搬过来。

**Raycast** — https://www.raycast.com  
近黑 + 一种强调色 + 轻玻璃。登录/onboarding 像开机仪式。  
偷：少 chrome、大预览、强调色只用在主行动。  
不偷：启动器的卡片墙（监测台会散）。

**Resend** — https://resend.com  
暗色后台如何既空又密：侧栏稳、内容区大、主按钮白底黑字。  
偷：主 CTA 用「反色」（暗底上的白纽扣），而不是品牌色大色块。

### 4.2 密度 / 权力感（监测专用）

**Palantir Gotham** — https://www.palantir.com/platforms/gotham/  
监测作为权力感：多面板、图层、实时状态条、可拼布局。  
偷：分栏、状态条、对象可点选下钻。  
不偷：军绿色顶栏、地图中心、分类标签视觉（容易滑稽）。

**Bloomberg Terminal**  
密度即奢侈：等宽数字、琥珀/绿红、零装饰、键盘驱动。  
偷：数字用等宽、涨跌用语义色、把「很多数据」当成卖点而不是负担。  
不偷：1980 年代控件、十种功能色同时出现。

### 4.3 其他值得打开的

| 站点 | 偷什么 |
|---|---|
| https://railway.app | 把系统画成画布，而不是列表 |
| https://www.warp.dev | 终端感如何现代化，而不复古 |
| https://cursor.com | AI 产品如何不做成 ChatGPT 套壳 |
| https://dashboard.stripe.com | 表格即界面，数字排版 |
| https://www.tinybird.co / https://axiom.co | 数据产品的暗色 denseness |
| https://cal.com / https://dub.co | 小产品如何用 Linear 语法做出自己的脸 |

### 4.4 中文产品（少 Linear 克隆、多气质）

多数国内云控制台（阿里云、火山引擎控制台）仍是开源后台变体，**不要当视觉参考**。可看：

- 即梦、Kimi、DeepSeek 的 **营销站 / 产品壳**（不是它们的后台表格）
- 少数派、少数高质量作品集站：中文排版、字号层级

中文 GEO 产品的真正机会：国际站不会认真做「豆包 / 元宝 / 千问」的平台气质。平台芯片、回答截图、引用小票可以做成识别度，而不是再画一套蓝按钮。

## 5. 登录页：开源味最重的位置

### 5.1 反模式（禁止）

```
[灰或浅暗背景]
    ┌─────────────────┐
    │   LOGO          │
    │   欢迎回来       │
    │   邮箱           │
    │   密码           │
    │   [ 登 录 ]      │
    │   或用 GitHub    │
    └─────────────────┘
```

再换配色、加模糊光、加 3D 插画，都还是同一张脸。

### 5.2 三种成立的结构

**① 左右劈开（首选）**

- 左 55–65%：活的产品。推荐「正在生成的 AI 回答」，品牌名被点亮，引用小票浮出。
- 右 35–45%：表单。无卡片，或只有一条极淡的竖分割。
- 参考气质：Linear 登录、多数顶级 devtools。

**② 满屏虚无**

- 近黑、巨大字标、表单极小、身份按钮为主。
- 参考：https://vercel.com/login
- 贵在什么都没有。要求字标和字体必须过硬。

**③ 开机仪式**

- 全屏极弱网格 / 噪声。光标、短动效、一句产品句。
- 输入即进入控制室。适合路线 B。
- 动效必须短（< 800ms），禁止矩阵雨、粒子爆炸。

### 5.3 登录文案

| 不要 | 要 |
|---|---|
| 欢迎回来 | 看 AI 怎么提到你 |
| 登录以继续 | 进入监测台 |
| 一站式生成引擎优化平台 | 豆包 / DeepSeek / 元宝 里的品牌可见度 |
| 请输入您的邮箱 | 工作邮箱 |
| 忘记密码？ | 重置 |

主按钮不要写「登录」，可以写「进入」或「开始监测」。次按钮才是「用邮箱继续」。

## 6. 签名物件（全站只养这一个）

没有签名物件，暗色主题 = 换了皮肤的开源后台。

**GEO 最该用的签名物件：Answer Canvas（回答画布）**

一段正在生成的模型回答。

- 品牌首次出现：强调色高亮（不是黄荧光笔）
- 竞品出现：次级标记，可对比
- 引用：行内小票（域名 favicon + 标题），可点
- 模型名 / 时间戳用等宽、低对比，贴在角落
- 登录页播这一段；监测台的「一次提及」还是这一段；报告封面还是这一段

复用三次以上才叫识别度。不要同时上：地球、粒子、神经网络、扫描线、彩虹图。选一个。

次选（若回答流做不稳）：

- 引用关系图（源 → 模型 → 回答）
- 可见度面积图，单色，带极弱网格
- 平台芯片墙（DeepSeek / 豆包 / 元宝…）做成硬件开关，而不是 checkbox 列表

## 7. 设计系统最低配置（先毁默认 token）

在画任何页面之前，先锁这张表。shadcn 可以留，**默认 token 必须换**。

### 7.1 颜色

路线 A+B 建议：

| Token | 建议 | 禁止 |
|---|---|---|
| 画布 | `#07080A` 或更冷的近黑 | `#0F172A`（一眼 Tailwind slate） |
| 表面 1 | 比画布亮 4–8% | 大面积 `#111827` 卡片 |
| 表面 2 | 再亮一点，仅用于抬起 | 每块都套白边卡片 |
| 边框 | `white / 8%` 左右 | 实色 `#E5E7EB` / `#333` |
| 主文字 | 近白，略压到 92% | 纯 `#FFF` 大段正文 |
| 次文字 | 白 48–62% | gray-400 一刀切 |
| **强调色（只留一个）** | 磷光绿 / 冷氰 / 琥珀 三选一 | 同时用蓝+绿+紫+橙 |
| 语义色 | 涨绿 / 跌红 / 中性琥珀，只给数字 | 按钮也用语义色 |
| 图表 | 强调色单色 + 2 个低饱和辅助 | 默认 Categorical 彩虹 |

强调色建议（按气质）：

- 磷光绿 `#3DFF9A` 一类：最「监测 / 终端」，易俗，要用暗、少、小
- 冷氰 `#5CE1E6` 一类：更科技、稍安全
- 琥珀 `#F5C15A` 一类：更编辑部、和路线 C 好接

主 CTA 在暗色上优先 **白底黑字**（Resend / Vercel），强调色留给数据、高亮、状态，不给大按钮。

### 7.2 字体

三层，不要更多：

1. **展示**：紧追踪无衬线，或一支衬线只给封面句  
   例：Geist / Satoshi / Instrument Sans；封面可用 Instrument Serif 或类似
2. **正文**：同一无衬线的 Regular / Medium
3. **数据 / 代码 / 时间戳：等宽**（Geist Mono / IBM Plex Mono / JetBrains Mono）

禁止：Inter 当唯一字体、中文用默认系统黑体而不调字号层级、数字不用等宽。

中文：选一款现代黑体（例如站酷极线 / 思源的显示级别），标题可略紧、略小字距；不要用阿里普惠 + 圆体。

### 7.3 形状与密度

- 半径：6–8px，或更小；登录和指挥台可以接近直角
- 不要全站 `rounded-2xl` + 大阴影
- 仪表盘 padding 小于落地页；监测台允许「满」
- 卡片不是默认容器：能用分割线就不要盒子

### 7.4 动效

- 时长 150–280ms，强调出场可以到 400ms
- easing：`cubic-bezier(0.16, 1, 0.3, 1)` 一类，禁止 bounce
- 回答流：打字 / 淡入按 token，不要整卡弹跳
- 禁止：矩阵雨、页面进场大 parallax、按钮缩放弹簧、光斑跟着鼠标到处走（最多一个极弱）

### 7.5 图标

- 线性、细、16–18px；不要 24px 圆底色块
- 平台用官方简标（DeepSeek / 豆包…），不要用通用「sparkle」代表所有模型
- 少用 emoji 当 UI 图标（Peec 的 👁️😊 是反例，看着轻松，不够贵）

## 8. 页面级具体建议

### 8.1 落地页（如果要做）

- Hero：一句立场 + 活的 Answer Canvas，不要六宫格特性
- 平台选择做成硬件开关 / 芯片，不要 checkbox 清单
- 三个大数（监测对话 / 品牌提及 / 引用文章）用等宽，不要卡片堆
- 案例走「一份报告的一页」，不要客户 logo 墙凑数
- 咨询：电话和微信可以留，但视觉上降级成页脚，不要做成整页 CTA

### 8.2 监测台首页

建议首屏只回答四个问题：

1. 我现在被提到多少（Visibility）
2. 排第几（Position）
3. 被说成什么样（Sentiment）
4. 谁在抢我的位置（竞品表）

下面才是：Prompt 列表、引用来源、模型对比。

布局骨架（B 的密度，A 的表面）：

```
[ 品牌 ▾ ] [ 7d | 30d | 自定义 ] [ 模型 ▾ ] [ 平台芯片… ]          [ 导出 ]
────────────────────────────────────────────────────────────────
 Visibility  23.4%  ↑1.2     Position  2.1  ↓0.3     Sentiment  +0.4
 [ 单色面积图 ────────────────────────────────── ]  [ 竞品榜 ──── ]
 [ 最近回答流 / Answer Canvas ────────────────── ]  [ 引用源 ──── ]
```

### 8.3 Prompt / 回答详情

- 一次 = 一条回答，不是一行表格
- 展开即 Answer Canvas
- 元数据（模型、温度、地域、时间）等宽、角落、可复制
- 引用小票可点到「源」页

### 8.4 报告 / 导出

这是路线 C 可以发力的地方：封面衬线标题、内页仍是 A+B。客户转发截图时，封面决定你贵不贵。

## 10. 执行顺序（比「找个网站抄」有效）

1. **写死一句立场**（见第 2 节）。贴在设计文件第一页。
2. **毁默认 token**：色、字、半径、边框、按钮。shadcn 留下，皮肤换掉。
3. **做签名物件**：Answer Canvas 一个组件，先在登录页跑通。
4. **登录页**：左右劈开，禁居中卡片。
5. **监测台首屏**：四指标骨架，单色图，竞品表。
6. **再铺 Prompts / Sources / Models**。
7. **文案过一遍**：删掉所有「欢迎 / 一站式 / 赋能」。
8. **打印测试**：把首页和登录截成图，缩小到手机宽。还能认出产品，才算有脸。

## 11. 对照清单（做完自己过一遍）

### 看起来仍像开源后台，如果：

- [ ] 登录是居中卡片
- [ ] 主字体是 Inter 或未调的系统黑体
- [ ] 主按钮是亮蓝 / indigo
- [ ] 每一块都是描边圆角卡片
- [ ] 图表是默认彩虹
- [ ] 有「欢迎回来」
- [ ] 暗色只是把背景改成 `#0F172A`
- [ ] 图标 24px + 彩色底圆
- [ ] 没有等宽数字
- [ ] 签名物件在登录和监测台不是同一个

### 开始像「有立场的监测产品」，如果：

- [ ] 一句话立场能被非设计听懂
- [ ] 全站一种强调色，且主要用在数据而不是按钮
- [ ] 登录左侧（或满屏）就是 Answer Canvas
- [ ] 数字等宽，涨跌有语义色
- [ ] 边框几乎看不见，层级靠底色微差
- [ ] 中文标题和英文 / 数字的字号关系是设计过的
- [ ] 平台（豆包、DeepSeek…）有自己的芯片脸
- [ ] 动效短、无 bounce
- [ ] 截图放到 Dribbble 上不会被误认为「shadcn dashboard template」

## 12. 本项目可直接采用的规格草案

> 尚未锁定品牌名。下列可当默认，等品牌名确定后再换字标。

- **立场**：暗色情报终端。一种磷光强调色。回答流是唯一装饰。
- **壳**：路线 A（Linear 语法）
- **核心**：路线 B（回答流 + 密度）
- **报告封面**：路线 C 的衬线标题
- **强调色**：冷氰或磷光绿（二选一，登录页做一次 A/B 即可）
- **登录结构**：左右劈开
- **首屏指标**：Visibility / Position / Sentiment + 竞品
- **平台**：DeepSeek、豆包、腾讯元宝、千问、文心、Kimi（芯片，可多选）
- **组件库**：可以 shadcn，必须换 token；不要用现成 dashboard template
- **不做什么**：地球、粒子网、彩虹图、居中登录卡、微信二维码当 Hero
